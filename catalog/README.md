# The Outpost catalogue

The catalogue is what Explore offers: where freely available content comes from, plus
what ships with Outpost. Nothing is fetched until a person asks.

```
manifests/                 one JSON file per manifest
bundled/                   what ships: radio/ (Outpost's own sheets), logbook73/ (generated books)
schema/manifest.schema.json   the format, generated from the server's code
packs.json                 named sets of entries
map-regions.json           ready-made map regions (generated)
route-sources.json         the servers "Find a route" may ask
repeater-sources.json      where repeater lists can be had, and which Outpost may fetch
```

People running Outpost can add manifests in the same format to
`<data directory>/catalog/` (bundled files in `catalog/bundled/` there). Shipped
manifests are read first, so a later file cannot replace their entries.

## The format

Follow [`schema/manifest.schema.json`](schema/manifest.schema.json)
(`"$schema": "../schema/manifest.schema.json"`).

```json
{
  "schemaVersion": 1,
  "id": "my-manifest",
  "name": "My manifest",
  "description": "What this list is for.",
  "maintainers": ["Who looks after it"],
  "downloadHosts": ["opds.library.kiwix.org", "lb.download.kiwix.org"],
  "entries": [
    {
      "id": "kiwix.wikipedia-en-100",
      "name": "Wikipedia 100",
      "description": "What a person gets, in a sentence or two.",
      "category": "encyclopedias",
      "publisher": "Wikipedia",
      "language": "en",
      "format": "zim",
      "license": "CC BY-SA 4.0",
      "attribution": "Wikipedia contributors. Packaged as a ZIM archive by the Kiwix project.",
      "lastVerified": "2026-11-15",
      "sizeBytes": 333000000,
      "source": { "type": "kiwix", "name": "wikipedia_en_100", "flavour": "" }
    }
  ]
}
```

- `id`: unique across all manifests, lower-case words joined by dots or hyphens.
- `category`: `survival`, `climbing`, `medicine`, `food`, `agriculture`, `engineering`, `repair`,
  `radio`, `navigation`, `preparedness`, `encyclopedias`, `science`, `reference`,
  `reading` (books read for pleasure) or `maps`.
- `sizeBytes`: an estimate, shown until the source gives the real size.
- `downloadHosts`: every host an entry's first request may go to. Outpost contacts no
  host that no manifest lists. Empty when every entry ships with Outpost.

A `source` is one of:

- `{ "type": "kiwix", "name": "...", "flavour": "..." }`: a book in the
  [Kiwix library](https://library.kiwix.org); `flavour` is `maxi`, `nopic`, `mini` or `""`
  for a single edition. Outpost takes the address, size and SHA-256 from the feed just
  before downloading. Never write a `.zim` address: Kiwix rebuilds books every month or
  two and removes old builds.
- `{ "type": "http", "url": "https://...", "sha256": "...", "sizeBytes": 0, "version": "..." }`:
  a file at a fixed address, with the checksum and size of the file as you checked it
  (required for shipped entries). With both, a catalogue refresh never contacts the
  publisher.
- `{ "type": "bundled", "file": "radio/uk-amateur-bands.md", "version": "2026-11-15" }`:
  a Markdown, PDF, EPUB or HTML file in `bundled/` (`format` says which). Explore shows it
  as "Included with Outpost"; adding it copies it into the library, offline. A higher
  `version` in a later release is offered as an update.

  Or a **book**, a folder of Markdown chapters read in order, named by `book` in place of
  `file`:

  ```json
  "source": {
    "type": "bundled",
    "version": "2026-11-12",
    "book": {
      "folder": "logbook73/g90",
      "sections": [
        {
          "title": "Introduction",
          "chapters": [
            { "key": "overview", "number": "00", "title": "Why the G90 still earns its place",
              "summary": "What this radio is and who it suits.", "file": "00-overview.md" }
          ]
        }
      ]
    }
  }
  ```

  Sections and chapters are in reading order. A chapter's `key` (unique in the book,
  lower-case with hyphens) names it in links and must not change between versions;
  `number` is printed in the contents. `format` is `markdown`. Adding the book copies its
  chapters to `collections/books/<entry id>`, one document each, so search lands on the
  chapter; removing it removes them.

## Rules for entries

1. **Official endpoints only**: the publisher's own service or one it endorses (as Kiwix
   for the projects it packages). No re-uploads, shorteners or mirrors.
2. **State the licence you checked at the source.** If you could not, write
   `"license": "See source"` with a `licenseNote` containing "not been verified".
3. **No one else's content here.** `bundled/radio/` holds sheets written for Outpost,
   each ending with the date checked, its sources and what it does not cover.
   `bundled/logbook73/` holds the LogBook73 handbook and guides (MIT, by this project's
   author), generated by `pnpm catalog:import-logbook73 <path>` with
   `manifests/logbook73.json` and the `radio-learning` and `radio-guides` packs; never
   edit them by hand. List a publisher's document with an `http` source instead.
4. **Describe plainly** what a person gets; each edition is its own entry, named by what
   differs ("without images"). Names are unique across the catalogue.
5. **https only**, every host in `downloadHosts`.
6. **Go gently.** Read the terms and `robots.txt` first; do not list a source that
   forbids automated or stored copies, and take addresses from the publisher's own
   listing rather than crawling.

## Links into the catalogue

A Markdown document can link to an entry, a chapter of a bundled book, or a heading in it:

```
[the handbook](outpost:entry/logbook73.handbook)
[Decibels](outpost:entry/logbook73.handbook/decibels)
[the 3 dB rule](outpost:entry/logbook73.handbook/decibels#the-3-db-rule)
```

An installed entry opens; otherwise the link leads to it in Explore. Any other form
shows as plain words.

## Packs

A pack names entries usually wanted together; it holds nothing itself. Explore lists packs
first, and fetching one queues what is not installed. Packs are in `packs.json` (a
person's own in `<data directory>/catalog/packs.json`):

```json
{
  "schemaVersion": 1,
  "packs": [
    { "id": "first-things", "name": "First things",
      "description": "What it is for, for the person choosing.",
      "entries": ["ready.emergency-supply-list", "who.basic-emergency-care"] }
  ]
}
```

`id` is lower-case with hyphens and `name` unique; `entries` are in listing order, and an
unknown id is reported by the validator and left out in the app. Keep a pack to what a
home connection fetches in one go (shipped packs stay under about 1.5 GB). Say what it is
for, not its size. Optional `countries` (ISO codes) lists it first where Home is in one.

## Repeater sources

`repeater-sources.json` says, country by country, whether Outpost may fetch a repeater
list on a press (`fetch`), only link to it with steps to download by hand (`link`), or has
nothing (`none`). A list is fetched only from a `fetch` source's address. `fetch` needs
the publisher's terms and `robots.txt` read and allowing it, recorded in `why`,
`termsUrl`, `termsNote` and `termsRead` ([sources.md](../docs/sources.md)); when in doubt
it is `link`. Shipped sources are `https` and wait at least ten seconds between requests.
Keeping a file of your own is in [radio.md](../docs/radio.md).

## Route sources

`route-sources.json` lists the Overpass servers "Find a route" may send a search to, and
no other host is asked.

```json
{
  "schemaVersion": 1,
  "sources": [
    { "id": "private-coffee", "name": "Private.coffee", "type": "overpass",
      "endpoint": "https://overpass.private.coffee/api/interpreter",
      "operator": "Private.coffee, a non-profit association in Austria",
      "coverage": "The whole world", "bbox": null,
      "termsUrl": "https://overpass.private.coffee/",
      "termsNote": "What the operator's terms say, and where.",
      "lastVerified": "2026-11-16" }
  ]
}
```

- `endpoint`: `https`, no credentials or query. `operator` and `coverage` are shown before
  a search.
- `bbox` (`[west, south, east, north]`, drawn inside what the server holds): a view whose
  middle is inside it asks that server first; a source with none is asked elsewhere.
  `defaultSource` (not in the shipped file) names one source for everywhere.
- Read the operator's terms on the day and record them in `termsNote`. A server whose
  operator asks applications not to depend on it is not listed (so not `overpass-api.de`;
  see [sources.md](../docs/sources.md)). One question per action by a person, never on a
  timer.
- People add their own in `<data directory>/catalog/routes/route-sources.json`, where
  `http` is allowed and `"replaceShipped": true` leaves the shipped ones out.

## Checking entries

```
node apps/server/src/cli/validate-catalog.ts            # format, ids, hosts, bundled files, schema
node apps/server/src/cli/validate-catalog.ts --online   # also asks each source
```

The offline check (also run in the test suite) confirms every bundled file or chapter is
present, UTF-8, opens with its title and has a version, and that nothing in `bundled/` is
unlisted. The online check asks one host at a time, ten seconds apart (`--delay
<seconds>`), falls back to the first byte where `HEAD` is refused, and `--skip-host <host>`
leaves a host unasked (counted as not checked). Kiwix's hosts are skipped unless
`--include-kiwix` is given: its `robots.txt` asks automated clients to stay out (a
person's Download is still fetched). Fix or remove what
no longer resolves, and set `lastVerified` to the day you checked. After changing
`apps/server/src/modules/catalog/manifest.ts`, regenerate the schema with `--write-schema`.

Explore takes a Kiwix book's size and version from the feed on Refresh (remembered
offline), and a bundled file's size by measuring it.
