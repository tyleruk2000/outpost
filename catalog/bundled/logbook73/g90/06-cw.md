# CW, the keyer and break-in operation

The G90 contains a capable electronic keyer, full break-in controls, adjustable sidetone, a narrow DSP passband and a simple decoder. The hard part is that all of them share the **KEY** button. Set the key wiring first, learn what QSK “off” means on this radio, and the rest becomes predictable.

## Connect the key safely

The KEY socket is `3.5 mm TRS`—tip, ring and sleeve. A paddle uses tip and ring for its two contacts with sleeve common. A straight key needs the firmware's manual-key arrangement and the correct contacts. Do not push a mono TS plug or an improvised adapter into the live radio without verifying the wiring: shorting the wrong contact can key continuously.

Connect with power off. On first startup, set transmit power to 1 W and use a dummy load. Keep a hand near the power/PTT controls. If the radio transmits immediately, power down and inspect plug wiring before changing menus.

The `M/L/R` selection describes the key:

- `M` — manual/straight key;
- `L` — paddle orientation with the left contact assigned according to the displayed arrangement; and
- `R` — reversed paddle orientation.

Choose L or R by pressing the paddles and listening in practice mode. If dots and dashes are reversed, change L/R rather than rewiring a correctly made cable.

## The KEY short-press sequence

Repeatedly short-press **KEY** to move through six settings. Rotate the main dial to change the displayed value and press to finish.

### SPEED

Keyer speed is in words per minute. Start at `15–18 WPM` while learning or at the speed you can copy accurately. Sending at 28 WPM because your hand can produce it does not help if you cannot copy the reply.

MFK can be assigned `Key Speed` for quick adjustment. That is valuable when answering a slower caller: match them rather than forcing them upward.

### M/L/R

Select manual key or paddle orientation as above. A straight key should make RF only while held. A paddle feeds the electronic keyer, which generates consistent element timing.

### MODE — Iambic A or B

Iambic keying alternates dots and dashes while both paddles are squeezed.

- **Mode A** stops element generation when the squeeze is released.
- **Mode B** adds the alternate element in the common release condition, which experienced Mode B operators use in their character technique.

Neither is universally better. Choose the one learned and keep it consistent across radios; changing modes makes familiar muscle memory produce extra elements.

### QSK

QSK controls break-in and, importantly, whether normal keyed operation transmits. On the G90:

- `QSK ON` enables transmit while keying;
- `QSK OFF` is effectively practice/sidetone mode and does not radiate normal keyed RF.

When QSK is off, the CW mode indication may turn red. This is a common “CW will not transmit” cause, not a failed key socket.

### QSK Time

This is the delay between the last element and the radio settling back to receive. Short delay gives near full break-in, letting you hear between elements or words. Longer delay reduces relay/audio chatter and prevents rapid switching from chopping the sidetone or external amplifier sequencing.

Start long enough that operation sounds clean, then shorten to taste. If using an external amplifier, its switching specifications—not impatience—set the minimum safe delay.

### Ratio

Ratio adjusts dot-to-dash weighting around the standard `1:3`. Leave it at the default unless compensating for a specific keying feel after monitoring the transmitted envelope. Non-standard weighting can make otherwise accurate code tiring to copy.

## The FUNC + KEY sequence

Repeated `FUNC + KEY` actions reach CW monitor volume, sidetone pitch and receive bandwidth. Xiegu's wording and sequence around the bandwidth item has varied and one current document is internally unclear, so use the value displayed by the APP v1.81 head rather than memorising a pre-v1.75 number of presses.

### CW Volume

This is sidetone/monitor loudness, not transmitted power. Set it comfortably below fatiguing level. If you use headphones, reduce it before sending.

### CW Tone

The sidetone is the audio pitch representing a correctly tuned CW carrier. Pick a tone you can recognise easily, commonly `600–800 Hz`. Lower pitches are less tiring for some operators. Once chosen, tune received stations to the same pitch; the ΔF/CW indicator helps.

### CW receive bandwidth

Use about `500 Hz` for searching and ordinary QSOs. Narrow toward `300 Hz` on a crowded band or for the decoder. An extremely narrow passband requires exact centring and may ring. If a station disappears after narrowing, widen first rather than retuning blindly.

Current two-BPF editing remains available through MFK. The published CW default is approximately `−250…+250 Hz` (500 Hz). Reset both BPF windows if an old filter setting makes CW silent.

## Tune a CW signal correctly

1. Select CW and a 500 Hz filter.
2. Tune until the station's pitch matches the selected sidetone.
3. Watch for the ΔF/CW indication at the correct tone.
4. Narrow to about 300 Hz if needed.
5. Use `10 Hz` dial steps for final centring.

If a strong station sits close on one side, select CWR. The wanted signal remains Morse, but the receive sideband reverses, often moving the interferer outside the passband. Retune for the same sidetone after switching.

## The built-in decoder

Long-press **KEY** to toggle CW decoding. The decoder is an aid for clean, regular code, not a substitute for copying by ear. It works best when:

- the signal is strong and steady;
- the filter is about 300 Hz;
- the carrier is tuned exactly to the selected CW tone;
- keyer speed is near the sender's speed; and
- the sender uses machine-like spacing.

Human fists, QSB, multipath, noise and two stations in the filter produce errors. Do not repeat a decoded callsign on air until you have confirmed it. If the text becomes nonsense, widen briefly to check there is only one signal, recenter until ΔF responds, then narrow again.

The G90 decoder does not create message memories or an automatic CW caller. Current stock firmware lacks the X6100-style message/auto-call system.

## Semi-break-in versus full break-in

With a short QSK Time, the receiver returns between elements or words. This makes conversational CW responsive and lets you hear an interruption. It also switches the radio frequently. With a longer delay, the transmitter stays in its transmit state through a word or phrase, which is calmer for relays, amplifiers and some operators.

For a bare G90 at modest power, shorten until it feels natural and no clicks/chopped audio appear. With an amplifier, transverter or external relay, use semi-break-in and verify sequencing. Hot-switching an amplifier is expensive.

## CW transmit preparation

Before calling:

1. Confirm the key/paddle and `M/L/R` setting.
2. Select CW or CWR and a legal frequency.
3. Set power low.
4. Confirm QSK ON; use OFF only for practice.
5. Choose speed you can both send and copy.
6. Check filter, sidetone and QSK Time.
7. Tune the antenna if needed on a clear frequency.
8. Send your callsign once into a dummy load or station monitor and check element spacing.

The transmitter creates RF whenever the keyer commands it. The sidetone is not evidence that an antenna is matched, and a decoder display is not evidence that your transmitted note is clean.

## Practice without radiating

Set QSK OFF. With headphones and the desired speed/mode, practise characters and listen for consistent spacing. Because the keyer generates elements, focus on the gaps:

- one dot between elements of a character;
- three dots between letters; and
- seven dots between words.

Practise complete on-air exchanges: `CQ`, callsign, report, name/QTH, confirmation and sign-off. This makes the radio controls disappear when a real station answers.

Use a dummy load as a second practice stage with QSK ON and 1 W. A nearby receiver—with sufficient attenuation and separation—can reveal key clicks, unstable tone or RF entering audio equipment.

## Common CW faults

| Symptom                                 | Likely cause                                  | First fix                        |
| --------------------------------------- | --------------------------------------------- | -------------------------------- |
| Sidetone but no RF                      | QSK off                                       | Set QSK ON                       |
| Continuous TX                           | Wrong/mono key plug or short                  | Power down; verify TRS wiring    |
| Dots/dashes reversed                    | L/R orientation                               | Swap L ↔ R in KEY menu           |
| Extra element after squeeze             | Wrong Iambic mode for technique               | Choose learned A/B mode          |
| Cannot find station after narrow filter | Not centred/ringing                           | Return to 500 Hz and retune      |
| Decoder gibberish                       | Off pitch, QSB, wrong speed, multiple signals | 300 Hz, recenter ΔF, match speed |
| Relay chatters                          | QSK Time too short                            | Increase hang time               |
| S-meter absent                          | AGC off                                       | Select AGC-F/A                   |

## A practical CW baseline

| Setting  | Start                                  |
| -------- | -------------------------------------- |
| Mode     | CW; try CWR for one-sided interference |
| SPEED    | 15–20 WPM or sender's speed            |
| Key      | M for straight, correct L/R for paddle |
| Iambic   | Your learned A or B                    |
| QSK      | ON for air, OFF for silent practice    |
| QSK Time | Moderate, then shorten safely          |
| Ratio    | Default 1:3-style weighting            |
| Tone     | 600–800 Hz to preference               |
| Filter   | 500 Hz search, ~300 Hz crowded/decoder |
| AGC      | Fast                                   |
| RF Gain  | Only enough for band noise             |

## Key takeaways

- Verify the 3.5 mm TRS key wiring before power; a wrong adapter can key continuously.
- KEY short presses cover speed, wiring, Iambic mode, QSK, delay and ratio.
- QSK OFF is practice mode; it is the first thing to check when there is sidetone but no RF.
- FUNC+KEY reaches monitor volume, sidetone and receive bandwidth.
- The decoder needs a centred, clean, narrow signal and remains only an aid.
