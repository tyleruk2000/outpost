# Menu reference: every RT95 item at a glance

Hold `FUNC` to open **SELECT MENU**. Use `P4`, `P6` or the channel knob to move between menu groups; `P5` pages quickly; press `PUSH` to enter. Inside a group, turn the knob to choose an item, press `PUSH` so its value turns green, choose the value, then press `PUSH` or `P3` to save and leave.

This table follows the official manual's menu order. The manual contains one clear typo: it calls both Channel items 4 and 5 “No.4”. The display sequence and section numbering show that **T-DEC is item 5**, which is how it is indexed here.

## Key and DTMF groups

- **MINI KEY** assigns actions to front keys `P1`–`P6` in each function group.
- **HANDY KEY** controls microphone-keypad brightness (`OFF–31`) and assigns the programmable microphone actions exposed as `H-PA` through `H-PD` in the manual.
- **DTMF Menu 1** stores 16 outbound DTMF strings.
- **DTMF Menu 2** selects each digit and gap duration: `50`, `100`, `200`, `300` or `500 ms`.

Most amateur operators only need a live DTMF digit occasionally. Hold PTT and press the microphone number keys; keep the fleet-selective decode menus off unless a known system uses them.

## VFO values versus saved memories

Some changes made while recalling a memory are temporary and disappear when you change channel or power-cycle. A memory is a stored snapshot. For a lasting change, edit and save the channel properly or update the code plug. [Programming, backups and custom keys](outpost:entry/logbook73.guide.rt95/programming) explains the safe workflow.
